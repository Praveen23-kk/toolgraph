---
name: ui-smoke-test
description: Smoke-test a web UI in a real browser. Use when the user says "smoke test", "check the page" or "take a screenshot".
---

`mcp__playwright__browser_navigate` to the URL, `mcp__playwright__browser_snapshot` to read the page,
`mcp__playwright__browser_take_screenshot` for evidence, and `mcp__playwright__browser_console_messages` for errors.
